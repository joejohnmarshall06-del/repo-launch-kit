# Growth Playbook

This project is designed to be easy to understand, useful in one command, and shareable.

## Positioning

Short pitch:

> A zero-dependency CLI that turns any repository into a launch-ready open-source project.

## Launch Channels

- GitHub README with screenshots or terminal demo GIF.
- Hacker News "Show HN".
- Reddit communities for open source maintainers.
- Dev.to tutorial: "I made a CLI that audits your repo before launch".
- Product Hunt only after adding a web demo.

## Roadmap Toward 1000 Stars

1. Add npm publishing.
2. Add markdown report badges.
3. Add language-specific checks for Python, Go, Rust, and Java.
4. Add GitHub API mode to audit remote repositories.
5. Add `repo-launch-kit doctor --url owner/repo`.
6. Add a small web playground.
7. Add examples from real repositories.

## Maintainer Strategy

- Keep the CLI zero-dependency.
- Prefer practical fixes over abstract advice.
- Make every recommendation explainable.
- Avoid collecting tokens or private repo data.
